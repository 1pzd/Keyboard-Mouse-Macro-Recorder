# 键鼠宏录制器

录制键盘/鼠标操作并按时间顺序精确回放的自动化工具。支持长按与点按区分、无限循环回放，可用于重复性游戏操作自动化。

## 功能特性

- **精确录制**：捕获键盘按下/释放、鼠标点击、移动、滚轮，毫秒级时间戳
- **长按识别**：press/release 时间差自动标注「长按」(≥0.3s) 与「点按」
- **精确回放**：按录制时间差复现，长按行为天然还原
- **无限循环**：支持无限/指定次数循环，可调轮间间隔
- **速度控制**：0.1x ~ 10x 速度倍率
- **全局热键**：任何窗口下 F9/F10/F11 快速控制
- **脚本保存**：JSON 格式保存/加载宏脚本

## 安装

```bash
pip install -r requirements.txt
```

需要 Python 3.8+，Windows/macOS/Linux（全局热键在部分 Linux 桌面环境需要额外权限）。

## 使用

```bash
python main.py
```

### 快捷键

| 热键 | 功能 |
|------|------|
| F9   | 开始/停止录制 |
| F10  | 开始/停止回放 |
| F11  | 紧急停止（立即中止一切操作） |

### 操作流程

1. 点「开始录制」（或 F9），执行你要记录的操作
2. 点「停止录制」（或 F9），事件列表显示所有已录事件
3. 设置循环次数（0=无限）、轮间间隔、速度倍率
4. 点「开始回放」（或 F10）
5. 随时按 F11 紧急停止

### 事件列表标注

- 🟢 绿色背景 = 按键按下事件
- 🟡 黄色背景 = 长按事件（≥0.3s），详情栏显示按住时长
- 无色 = 点按、移动、滚轮事件

## 合规提示

**请在使用前确认目标游戏/软件的用户协议（ToS）允许宏/自动化操作。** 部分在线游戏的反作弊系统可能将输入自动化判定为违规行为。本工具仅供个人学习和合法的重复性任务自动化使用，使用者需自行承担合规风险。

## 技术说明

- **长按 vs 点按**：录制时 press 和 release 各记录为独立事件，回放按时间差精确复现，无需额外处理
- **鼠标移动节流**：默认 30 次/秒采样，避免事件过多导致文件膨胀
- **回放精度**：使用 `time.perf_counter()` + 可中断 sleep，避免累积误差
- **线程安全**：录制回调在 pynput 监听线程，GUI 更新通过 `root.after()` 调度到主线程
